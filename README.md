NOCTIVA is a modern, dark-themed movie and TV discovery web application designed for people who love exploring what to watch next. It provides a cinematic browsing experience with detailed information about movies and series, organized discovery, and a responsive interface across devices.

##  Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Alok477/NOCTIVA.git
```

### 2. Navigate to the project

```bash
cd NOCTIVA
```

### 3. Install dependencies

```bash
npm install
```

### 4. Configure environment variables

Create a `.env` file in the project root and add the required API and Firebase configuration used by the application.

Example:

```env
VITE_TMDB_API_KEY=your_tmdb_api_key

VITE_FIREBASE_API_KEY=your_firebase_api_key
VITE_FIREBASE_AUTH_DOMAIN=your_firebase_auth_domain
VITE_FIREBASE_PROJECT_ID=your_firebase_project_id
```

> Keep API keys and private configuration out of the repository. Use environment variables for deployment.

### 5. Start the development server

```bash
npm run dev
```

The application will then be available through the local development URL shown in your terminal.

##  Design Philosophy

NOCTIVA focuses on creating a **cinematic browsing experience rather than a traditional media catalog**.

The interface uses:

*  Dark visual language
*  Poster-focused content presentation
*  Cinematic spacing and typography
*  Interactive browsing
*  Responsive layouts
*  Movie-inspired visual hierarchy

The goal is to make discovering something to watch feel engaging and visually immersive.
